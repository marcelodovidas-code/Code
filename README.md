# Módulos VBA

Para utilizar los módulos en tus planillas de Excel:

1. Descargá el archivo `.bas` correspondiente desde este repositorio.
2. Abrí tu libro de Excel y presiona `Alt + F11` para abrir el editor de Visual Basic.
3. En el menú superior, selecciona **Archivo > Importar archivo...** (o presiona `Ctrl + M`).
4. Seleccioná el archivo `.bas` descargado y ¡listo!
